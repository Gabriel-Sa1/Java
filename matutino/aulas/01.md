## O Que é um Problema?

Um problema é uma situação em que existe um estado atual e se deseja chegar a algum resultado. "Organizar uma festa" é um problema, mas ainda é amplo demais para ser entregue a um computador. Não sabemos quantas pessoas participarão, qual é o orçamento, onde será o evento ou o que significa exatamente "organizar".

Um problema computacional é uma tarefa descrita de modo que informações possam ser representadas como dados e transformadas por regras precisas até a obtenção de um resultado verificável. Isso não quer dizer que o computador consiga resolver qualquer problema. Significa apenas que a parte entregue ao computador precisa ser formulada sem depender de adivinhação, intuição ou contexto oculto.

"Mostre a ficha de um aluno"

| Pergunta | Exemplo |
| -------- | ------- |
| Quais dados existem? | nome, idade, curso, matrícula |
| Como cada dado será representado? | texto, número inteiro, verdadeiro/falso |
| Qual resultado deve aparecer? | uma ficha formatada no terminal |
| Como verificaremos se está correto? | comparar a saída com os valores esperados |

Uma especificação poderia ser:

> O programa deve guardar o nome "Ana", a idade é 18, o curso é "ADS" e a informação de que a matrícula está ativa. Depois, deve exibir os dados em linhas separadas.

Essa descrição informa os dados, a transformação e o resultado. Não é código em Java mas é a definição do problema.

### Problemas Adequados/Inadequados

Calcular a área de um retângulo com X de altura e Y de base é um problema fácil de formular de maneira computacional, existem entradas, uma regra (matemática) e uma saída. Mas escolher o filme mais lindo do mundo não tem uma resposta objetiva sem que os critérios, dados e uma maneira de pontuação sejam definidos.

Muitos erros de código vêm de problemas que não são definidos. Se não sabemos o que deve acontecer de maneira exata, não existe uma implementação capaz de garantir o resultado correto.

## O Que é um Algoritmo?

Um algoritmo é uma sequência finita, ordenada e não-ambígua de etapas que transformam um estado em outro. Finita pois a sequência precisa terminar. Ordenada pois a posição das etapas pode alterar o resultado. Não-ambígua pois cada instrução deve ter interpretação precisa para quem executar ela.

Um algoritmo pode ter:

- entradas
- processamento
- saídas
- condições
- repetições

## O Que é uma Linguagem de Programação?

Uma linguagem de programação é um sistema formalizado para expressar instruções e dados. Ela tem vocabulário, símbolos e regras.

- Sintaxe: define quais combinações de símbolos são válidas. Esquecer `;` onde é exigido é um erro de sintaxe.
- Semântica: é o significado. `int idade = 18` é criar uma variável de número inteiro, chamada `idade` e iniciar ela com 18.
- Palavra-chave: é uma palavra reservada pela linguagem, como `public`, `class`, `static`, `void` e `int`.
- Identificador: ...
- Literal: é uma representação de valor no código, como `18`, `3.5`, `true`, `'A'` ou `"Ana"`.

## Paradigmas de Programação

Um paradigma de programação é uma maneira de estruturar programas.
Não é uma linguagem, uma mesma linguagem pode suportar mais de um paradigma.

### Programação Imperativa

```
coloque 10 em x
some 5 a x
mostre x
```

Java suporta esse estilo.

```
int x = 10;
x = x + 5;
System.out.println(x);
```

### Programação Orientada a Objetos (POO/OOP)

Os programas podem ser estruturados em torno de objetos que combinam estado e comportamento.

```java
class Conta {
    double saldo;

    void depositar(double valor) {
        saldo += valor;
    }
}
```

A classe descreve uma estrutura e comportamentos associados.

### Programação Funcional

A programação funcional enfatiza funções, composição, transformação de dados e redução de efeitos colaterais.

Java também possui recursos funcionais, como:

```java
lista.stream()
    .filter(x -> x > 10)
    .map(x -> x * 2)
    .toList();
```

### Paradigma não é regra de sintaxe

"Java é orientada à objetos"

não significa:

"Todo programa Java precisa usar herança, interfaces e dezenas de classes."

Paradigmas são modelos de organização e raciocínio

Aprender Java bem envolve saber quando uma abstração ajuda e quando ela apenas adiciona complexidade.

## main metódo
Um método é uma unidade de comportamento declarada em uma classe ou outro contexto permitido pela linguagem.

```java
public static void main(String[] args) {
    System.out.println("oi");
}
```

`main` é um método que serve como ponto de entrada de uma aplicação no protocolo tradicional de lançamento.

### `static`

Uma classe pode definir um tipo de objeto:

```java
class Pessoa {
    String nome;
}
```

### `public`

`public` é um modificador de acesso.

É uma indicação de que a declaração têm acesso público de acordo com as regras de acesso de Java.

No modelo tradicional de lançamento, o `main` clássico era declarado como público para que o mecanismo de lançamento pudesse encontrá-lo e invocá-lo.

### `void`

`void` indica que o método não retorna um valor.

compare:

```
int somar(int a, int b) {
    return a + b;
}
```

com:

```
void mostrarMensagem() {
    System.out.println("oi");
}
```

### `String[] args`

`String[]` é um array de `String`.

`args` é apenas o nome da variável.

## Dúvidas

### Por que existem tantas linguagens de programação?

Apesar de todas quererem fazer programas, programas possuem necessidades diferentes.

Algumas linguagens vão priorizar:

- controle sobre memória e hardware
- segurança
- produtividade
- simplicidade
- concorrência
- computação científica
- desenvolvimento web
- sistemas embarcados
- análise de dados
- programação funcional
- metaprogramação
- interoperabilidade
- desempenho previsível

Além disso, há uma questão histórica. As linguagens de programação são construídas sobre ferramentas, bibliotecas, comunidades e programas existentes. Uma linguagem nova não começa do zero em um mundo vazio.

Então, "qual é a melhor linguagem?" is a poorly asked question.
