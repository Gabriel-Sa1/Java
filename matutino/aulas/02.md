# Dados, Cálculos, Entrada e Testes

## Armazenamento de Dados: Variáveis e Constantes

Para processar informações, um programa precisa guardar elas na memória do computador. Pense na memória como um armário cheio de gavetas. Cada espaço de memória tem um tipo (o que ele pode guardar), um identificador (o nome que foi atribuído) e um conteúdo (o valor armazenado).

### Variáveis

Uma variável é um espaço alocado na memória cujo valor pode ser alterado durante a execução do programa. Em Java, que é uma linguagem de tipação "forte", é necessário declarar a variável antes de usar ela, com informações do tipo e nome. Depois, você pode atribuir um valor à ela, com o operador de atribuição `=`.

A declaração reserva o espaço na memória. A atribuição coloca o dado no espaço.

```java
// declaração
int idade;

// atribuição
idade = 20;

// declaração e inicialização
double price = 19.99;

// reatribuição
idade = 21;
```

### Tipos

Eles armazenam o valor.

- `int`: Armazena número inteiros. Ocupa 32 bits de memória e pode armazenar valores de ~-2 bilhões até +2 bilhões
- `double`: Armazena números de "ponto flutuante", ou seja, com casas decimais. Ocupa 64 bits e oferece mais precisão, sendo o padrão para cálculos matemáticos.
- `boolean`: Armazena valores lógicos, admitindo dois estados: `true` ou `false`. É a base de toda a lógica de decisão.
- `char`: Armazena um único caractere Unicode.
